# 两地光（Two-Place Light）

一台只关心光的小设备：把**威海**（老家）与**天津**（学校）此刻的太阳高度、日出日落，以及
今天还剩多少光，放在同一块 240×320 的屏上。

天文计算全部在 MCU 上完成。没有图片素材，没有音频，除了基线已启用的两个 Montserrat 字号之外
没有额外字体。网络只用来做一件事：对时。

## 操作

| 操作 | 作用 |
| --- | --- |
| `上` / `下` | 上一页 / 下一页 |
| `确定` 短按 | 背光 100% → 60% → 30% 循环 |
| `确定` 长按 | 息屏；任意键唤醒 |
| `下` 长按 | 打开设置热点（换城市、时区、Wi-Fi） |
| 抢时间阶段 `确定` 长按 | 放弃联网，改用手动对时 |
| 对时页 `上` / `下` | 调整高亮字段 |
| 对时页 `确定` 短按 | 下一字段；在最后一个字段上即提交 |
| 对时页 `确定` 长按 | 取消 |
| 设置热点开着时按任意键 | 关掉热点 |

## 三个页面

1. **ARC** —— 全天太阳高度画成两条曲线（蓝＝城市 1，橙＝城市 2）+ 地平线，以及一根暗色的
   竖直"现在"标记。
2. **PAIR** —— 两边数字并排：此刻高度、日出、日落，以及哪边更亮。
3. **LEFT** —— 距离下一次日落/日出还有多久、民用晨昏时刻、明天比今天多或少多少光。

## 两个城市

这两个坐标不是编译期常量，而是运行时的数据：从 NVS 读，读不到就回退出厂的威海
（37.51 N, 122.12 E）和天津（39.08 N, 117.20 E）。改它们走设置页：

- 名字只收 ASCII（字母、数字、空格、`-`、`_`，最长 12 字符）：屏上跑的是 Montserrat，
  没有中文字形，而加字库为了省 flash 被主动放弃了。
- 纬度 −90..90，经度 −180..180。
- 两地共用**一个** UTC 偏移（分钟，默认 `480` 即 UTC+8），必须是 15 的整数倍。跨时区的两座
  城市暂不支持：本地日边界、曲线和"今天"都按这一个偏移算。

## 时间从哪来

RTC 里没有可信时间时，按下面顺序抢时间：

1. **Wi-Fi + SNTP**。有凭证就连路由器，问 `ntp.aliyun.com` 要时间，同步成功就写进 RTC。
2. **设置热点**。没凭证或连不上时开一个 SoftAP `TwoPlaceLight`（WPA2，密码 `lingan-is-so-cute`）。
   手机连上它，打开 `http://192.168.4.1`，改两座城市、UTC 偏移，也可以顺便换 Wi-Fi；
   设备存进 NVS 后重启。之后长按 `下` 可以随时再打开这一页。
   热点开着的时候，射频范围内谁都能访问这个配置页，所以它是一扇临时窗口，不是常驻服务。
3. **三键手动对时**。在第 1–2 步里长按 `确定` 直接跳过联网：`上/下` 调字段，`确定` 跳下一个，
   在分钟字段上再按一次提交，长按 `确定` 取消。

板子没有独立 RTC 芯片。时间由 ESP32-C3 的 RTC 经 newlib 维持
（`CONFIG_NEWLIB_TIME_SYSCALL_USE_RTC`），深睡眠期间不丢，但真正断电会丢——所以开机要走上面
这套流程。时间不可信时界面显示 `--:--`，不猜。

RTC 慢速时钟走的是片内 RC 振荡器（板上没有 32.768 kHz 晶振），所以保留下来的时间一天能偏出
几分钟，而且复位、重新刷机都不会把它清掉。因此只要有 Wi-Fi 凭证，固件就会重新对时：开机时
即使时间"看着有效"也校一次，之后每六小时在后台静默校一次。校时失败就继续用原来的时间，不会
把界面卡在联网页上。

## 文件

| 路径 | 职责 |
| --- | --- |
| `main/solar.c` | 太阳几何：赤纬、时差、日出日落、高度角、方位角 |
| `main/civil_time.c` | epoch ↔ 日历换算、本地日边界 |
| `main/places.c` | 运行时坐标与时区状态，以及纯校验规则 |
| `main/places_store.c` | 坐标的 NVS 存取（坏字段逐个回退默认值） |
| `main/app_clock.c` | RTC 读写与最近一次对时记录（NVS） |
| `main/app_state.c` | 页面与背光状态机 |
| `main/app_setup.c` | 三键对时状态机 |
| `main/net_wifi.c` | STA 连接、设置热点 + HTTP 页面、凭证存取 |
| `main/net_time.c` | SNTP 对时 |
| `main/prov_parse.c` | 设置表单解析（URL 解码、范围与长度规则） |
| `main/ui.c` | 五个页面 |

`main/demo_*.c` 与基线的像素菜单仍留在树里作参考，但已不参与构建：派生应用必须有自己的界面。

## 还没做

- 没有网络时的可信走时：没有 Wi-Fi 时只剩 RC 推出来的 RTC，两次手动对时之间的误差没有上限。
- 真正的空闲深睡眠（`bsp_display_prepare_deep_sleep` + `bsp_button_prepare_deep_sleep`，
  以及 `main/key_guard.h` 里的唤醒键屏蔽）。注意：长按 `确定` 只是关屏（息屏），CPU 与 Wi-Fi
  仍在跑，所以那不等于省电——只是看不见。
- 跨时区的两座城市（目前两地共用一个 UTC 偏移）。
- 背光档位跨重启保存。
- 中文标签；加之前先过一遍字体检查清单。

## 换成你关心的两个地方

在设备上长按 `下` 打开设置热点，手机连 `TwoPlaceLight` 后打开 `http://192.168.4.1` 改，
保存后自动重启。出厂默认是威海与天津，写在 `main/places.c` 的 `PLACES_DEFAULT` 里，
坐标取市中心附近（±0.05°），远小于一分钟的日出误差量级。
